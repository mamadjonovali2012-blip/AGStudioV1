# AGStudio V1 · 3.0.0

Параметрический 3D-моделер в духе **OpenSCAD** с **билингвальным языком** — команды пишутся и **по-русски**, и **по-английски** (их можно смешивать).

> **Новое в 3.0.0:** ~99 билингвальных команд, 20+ математических функций, 20+ примитивов (капсула, эллипсоид, пирамида, тетраэдр, октаэдр, звезда, кольцо, ломтик, тело-вращения, труба, полусфера и др.), десятки трансформаций (скрутка, изгиб, перекос, сужение, взрыв, волна, спираль, массив, шум), **анимация-автовращение** и **проекции**.
>
> *В 2.x:* команда `глитч()/glitch()`, интерфейс в стиле OpenSCAD, нативные установщики Windows и Linux, каркасный режим, скриншоты PNG.

---

## ⚡ Главная фишка — команда `глитч()/glitch()`

Разрезает любую фигуру на **2+ части** с «цифровым шумом» — случайными сдвигами, поворотами и масштабированием каждого слоя. Идеально для декоративного разрушения, «разлома» и эффекта глитча.

```openscad
// Разрезать куб на 6 слоёв вдоль оси X (с лёгким наклоном оси)
глитч([1, 0.2, 0], 6) {
  куб(8);
}

// "Цифровой взрыв" сферы на 8 частей
glitch([0, 0, 1], 8) {
  sphere(r=4);
}
```

**Синтаксис:** `глитч([ось], количество_частей) { фигура }` / `glitch([axis], parts) { shape }`

## 🚀 Установка (готовые сборки)

### Windows
1. Запусти **`release/AGStudioV1-Setup-2.0.0.exe`**
2. Следуй шагам установщика (можно выбрать папку установки)
3. На рабочем столе и в меню «Пуск» появится **AGStudio V1**

> Портативная версия — `release/win-unpacked/AGStudio V1.exe` (без установки).

### Linux / AppImage
```bash
# сборка AppImage (нужны node/npm и зависимости electron-builder)
npm install
npm run dist:linux     # → release/AGStudioV1-2.0.0.AppImage

# запуск
chmod +x release/AGStudioV1-2.0.0.AppImage
./release/AGStudioV1-2.0.0.AppImage
```

## 🛠 Разработка

```bash
npm install
npm run dev            # Vite dev-сервер на http://localhost:5173

npm run build          # production web → dist/
npm run electron       # предпросмотр нативного окна (из dist)

npm run dist           # собрать установщики текущей ОС
npm run dist:win       # собрать Windows-установщик (NSIS)
npm run dist:linux     # собрать Linux AppImage
```

## Пример

```openscad
// Разность: куб минус цилиндры (русские команды)
разность() {
  куб(10);
  перенести([5, 5, -0.1]) цилиндр(радиус=2, высота=11);
  перенести([2, 2, -0.1]) цилиндр(радиус=1.5, высота=11);
}

// Тот же код по-английски
difference() {
  cube(10);
  translate([5, 5, -0.1]) cylinder(r=2, h=11);
  translate([2, 2, -0.1]) cylinder(r=1.5, h=11);
}
```

## Стек

- [Vite](https://vitejs.dev) + [Electron](https://www.electronjs.org) — десктоп
- [Three.js](https://threejs.org) — 3D-рендер
- [JSCAD Modeling](https://github.com/jscad/OpenJSCAD.org) — точный CSG-движок
- [CodeMirror 6](https://codemirror.net) — редактор кода с подсветкой
- Собственный парсер и интерпретатор (в `src/lang/`)

## Структура

```
agstudio-v1/
├── electron/                # нативная оболочка (main/preload)
├── build/                   # глитч-ассеты установщиков (icon/sidebar/banner)
├── scripts/                 # генератор ассетов
├── release/                 # собранные установщики
└── src/
    ├── main.js              # точка входа, UI, рендер, виды
    ├── examples.js          # билингвальные примеры (с глитчем)
    ├── lang/
    │   ├── tokenizer.js     # лексический анализ (RU/EN)
    │   ├── highlight.js     # подсветка CodeMirror
    │   ├── parser.js        # синтаксис → AST
    │   └── interpreter.js   # AST → JSCAD геометрия (+ glitch)
    └── renderer/
        ├── geometry.js      # Three.js mesh + STL/OBJ/PNG
        └── theme.js         # темы и пресеты фона
```
